# App-only blog covers

The website has no photo for these posts, so they showed only the post number. Angad asked
for pictures on 2026-10-07. `scripts/port-blog.mjs` uses a cover from here when the website
has none; once the website adds its own, the website's wins. Each is cropped to 21:9, like
the website's covers. All are CC0 or public domain, so no credit is required; this records
where each came from.
